# Finzer – AI-Powered Financial Advisor Platform

Finzer is an AI-driven financial advisor platform designed to simplify personal finance management through intelligent automation, investment analytics, and conversational AI.  
It helps users track expenses, plan investments, and make data-backed financial decisions in an intuitive dashboard environment.

---

## 🧩 Overview
Finzer integrates **Machine Learning**, **Generative AI**, and modern **full-stack web technologies** to build an end-to-end intelligent financial management system.

The platform offers:
- Automated budget categorization using ML models  
- Personalized investment recommendations  
- AI chatbot for finance-related queries  
- Real-time financial insights and visual analytics  

---

## 💡 Features
- **Budget Categorization:** ML model automatically classifies transactions into spending categories (e.g., Food, Rent, Utilities, etc.)  
- **Investment Planning:** Uses regression models to forecast investment returns based on user profiles and goals.  
- **AI Chatbot:** Fine-tuned financial advisor that answers queries on budgeting, mutual funds, and savings strategies.  
- **Analytics Dashboard:** Visual insights into expenses, savings, and portfolio growth using React + Chart.js.  
- **Authentication & Security:** Role-based access with JWT authentication for secure data management.  

---

## 🧠 AI & ML Components
- **Transaction Classifier:** Trained ML model (Scikit-learn / XGBoost) for expense categorization.  
- **Investment Predictor:** Regression-based model predicting portfolio growth.  
- **Chatbot:** Fine-tuned transformer-based model (e.g., DistilBERT) for finance-specific conversations.  
- **Data Preprocessing:** Cleaning, tokenization, and entity extraction for financial texts using NLTK and spaCy.

---

## ⚙️ Tech Stack
**Backend:** Python, FastAPI, Scikit-learn  
**Frontend:** React.js, TailwindCSS, Chart.js  
**AI/ML:** Transformers, NLTK, Scikit-learn, Pandas  
**Database:** PostgreSQL  
**Authentication:** JWT Tokens  
**Deployment:** Docker, Render / Google Cloud Run
